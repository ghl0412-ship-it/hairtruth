# HairTruth P0 보안 전환 기록

## 목적

이 저장소는 서버 기반 MVP 전환 전까지 정적 정보 열람 기능만 제공한다. P0 보안 작업으로 브라우저 `localStorage` 기반 회원·로그인·관리자·후기 승인 구조를 중단하고, 영수증 업로드와 후기 작성·승인 화면 동작을 **베타 데이터 수집 준비 중** 안내로 전환했다.

## 수정 전 위험

- 프론트엔드 코드와 Git 이력에 관리자 비밀번호 및 관리자 판별 로직이 존재했다.
- 회원·세션·관리자 권한이 브라우저 `localStorage`에 저장되어 변조 가능했다.
- 후기와 영수증이 서버 검증 없이 브라우저에 저장되고 인증된 것처럼 보일 수 있었다.
- 빈 이용약관·개인정보 처리방침 링크가 존재했다.
- 사용자 입력을 `innerHTML`로 출력하는 다수 지점이 있었다.

## 수정 파일 목록

| 파일 | 변경 내용 |
|---|---|
| `index.html` | 하드코딩 관리자 비밀번호·관리자 세션 키·클라이언트 인증 저장소 키를 제거했다. 로그인, 회원가입, 카카오 로그인, 영수증 업로드, 후기 제출, 후기 승인·반려, 데이터 내보내기·초기화, 관리자 열기 경로를 베타 안내로 비활성화했다. 약관 링크를 실제 페이지로 연결했다. |
| `shared.js` | 분리 페이지에서 사용하던 localStorage 회원·세션·관리자 판별을 제거하고 로그인·후기 작성 경로를 베타 안내로 비활성화했다. |
| `qa.html` | 클라이언트 관리자 ID 판별을 제거하고 질문·답변 등록을 베타 안내로 비활성화했다. |
| `terms.html` | 정식 서비스 전 법률 검토를 위한 이용약관 구조 페이지를 추가했다. |
| `privacy.html` | 정식 서비스 전 개인정보 처리방침 구조 페이지를 추가했다. |
| `XSS_RISK_REGISTER.md` | `innerHTML` 기반 출력 지점과 재개 전 필수 조치를 기록했다. |
| `package.json` | 외부 의존성 없는 `npm test` 정적 검사 진입점을 추가했다. |
| `scripts/static-check.mjs` | 하드코딩 관리자 식별자·클라이언트 인증 저장 키 재도입 여부, 베타 비활성화 경로, 약관 링크, 인라인 JavaScript 문법을 검사한다. |

## 남은 보안 위험

- Git 이력에 이미 노출된 과거 관리자 자격증명은 코드 삭제만으로 제거되지 않는다. 운영 재개 전 해당 자격증명을 폐기·교체하고, 필요 시 Git 이력 정리 절차를 별도로 수행해야 한다.
- `XSS_RISK_REGISTER.md`의 High 항목은 현재 기능이 비활성화되어 있어 즉시 노출 경로가 줄었지만, 후기·Q&A·관리자 기능을 재개하기 전에 반드시 `textContent` 또는 검증된 sanitizer 방식으로 수정해야 한다.
- 정적 GitHub Pages만으로는 안전한 인증, 권한 검증, 비공개 영수증 저장, 개인정보 삭제, 감사 로그를 구현할 수 없다.
- 이용약관과 개인정보 처리방침은 정식 서비스 전 실제 수집 항목·보유기간·책임자·문의 채널을 반영해 법률 및 개인정보 보호 검토가 필요하다.

## 테스트

실행 명령:

```powershell
npm.cmd test
```

정적 검사는 다음을 확인한다.

- 관리자 자격증명 또는 클라이언트 관리자 판별 식별자가 현재 소스에 없는지
- 브라우저 기반 인증 저장 키가 재도입되지 않았는지
- 로그인, 회원가입, 영수증 업로드, 후기 제출·승인·반려가 베타 안내로 차단되는지
- 이용약관·개인정보 처리방침 링크와 XSS 목록 문서가 존재하는지
- 모든 HTML 인라인 JavaScript의 문법이 유효한지

배포는 수행하지 않았다. 이 정적 검사는 서버 인증·DB 권한·파일 업로드·실제 브라우저 UI를 검증하지 않으며, 서버 기반 MVP가 준비된 뒤 통합/E2E 보안 테스트가 추가로 필요하다.
